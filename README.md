<h1>DOOM2016</h1>
<p>《魔鬼終結者2》熔岩大拇指（Terminator 2）• 彩蛋內容： 在第三關「鑄造廠（Foundry）」或其他地圖中，若玩家不小心跳入滾燙的阿根廷能源熔岩中死亡，主角「毀滅戰士（Doomguy）」在身體完全沉入熔岩前的最後一刻，會向鏡頭豎起大拇指。這完全複製了《魔鬼終結者2》中 T-800 結尾沉入鋼水時的經典告別一幕。</p>

<p>在《毀滅戰士 2016》（DOOM 2016）中，「Doomguy 玩偶（Doomguy Model）」是遊戲中非常經典的隱藏彩蛋兼收集要素。遊戲內總共有 26 隻玩偶，散落在 13 個主線任務中，每個關卡各有 2 隻。</p>
